# Simulatore di meccanismi 

Inizialmente pensato per simulare solo il siderostato di Foucault, in seguito è stato generalizzato per supportare generici
meccanismo descritti in file esterni cariicabili sul momento.

Creato con l'aiuto di Claude Sonnet 5.5, QWEN 3.7, Deepseek, Meta AI, ChatGPT e chi più ne ha più ne metta.
