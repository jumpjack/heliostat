# Simulatore di meccanismi 

Inizialmente pensato per simulare solo il siderostato di Foucault, in seguito è stato generalizzato per supportare generici
meccanismo descritti in file esterni cariicabili sul momento.

Creato con l'aiuto di Claude Sonnet 5.5, QWEN 3.7, Deepseek, Meta AI, ChatGPT e chi più ne ha più ne metta.

- [Simulatore](https://jumpjack.github.io/heliostat/simulatore/index.html)
- Macchine:
  - [siderostato di Foucault/Eichens](https://github.com/jumpjack/heliostat/blob/main/simulatore/machine-sideorstato-ok-2026-10-19.js)
  - eliostato di Foucault "[modello 1](https://github.com/jumpjack/heliostat/blob/main/simulatore/machine-eliostato1.js)"
  - [eliostato di Jacob's Gravesande](https://github.com/jumpjack/heliostat/blob/main/simulatore/gravesande.js)
  - [Prova di croce di malta ("geneva drive")](https://github.com/jumpjack/heliostat/blob/main/simulatore/geneva.js) (risolutore da perfezionare)
  - [Giunto pin/slot Antykithera](https://github.com/jumpjack/heliostat/blob/main/simulatore/antik.js)
  - [Mix](https://github.com/jumpjack/heliostat/blob/main/simulatore/mix.js)
